# kkutu-dict-docs

끄투코리아 끝말잇기 단어사전(<https://kkutu.lightstudio.kr/>) 사용법을 정리한 문서 사이트입니다.
사전 운영 문서가 아니라 사용자용 안내이며, 조건 검색을 어떻게 조합하면 되는지에 집중합니다.

- 사이트: <https://ha-am-dev.github.io/kkutu-dict-docs/>
- 치트시트: <https://ha-am-dev.github.io/kkutu-dict-docs/guide.html>

## 다루는 내용

- 시작·끝 글자, 포함 글자, 자모, 길이, 미션, 주제 조건의 조합
- 두음법칙·글자 정보 표시 같은 표시 옵션
- 결과가 0건일 때 조건을 빼는 순서
- 방어 단어를 고르는 기준

## 수정 방법

`index.html`, `guide.html`을 직접 고치고 `main`에 커밋하면 GitHub Pages가 다시 빌드합니다.
사전의 기능이 바뀌면 문서도 같이 고쳐 주세요. 확인되지 않은 기능은 쓰지 않습니다.

## 라이선스

문서 내용은 자유롭게 인용할 수 있습니다. 사전 서비스 자체의 이용 조건은 해당 사이트를 따릅니다.
