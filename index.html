끄투 사전, 조건을 조합해서 쓰는 방법

끝말잇기를 하다 막히는 순간은 대부분 "조건이 여러 개"일 때입니다. 시작 글자는 아는데 끝 글자가 문제라거나, 길이 제한과 미션까지 겹치는 경우죠. 이 문서는 끄투코리아 단어사전의 조건을 어떻게 조합하면 되는지 정리한 것입니다.

바로 쓰기 — 사전은 kkutu.lightstudio.kr에서 회원가입 없이 열립니다. 단어 하나를 눌러 /text/단어 주소로 들어가면 그 단어로 시작하거나 끝나는 목록까지 이어서 볼 수 있습니다.

1. 기본은 "시작 글자"와 "끝 글자"

가장 많이 쓰는 조합입니다. 내 차례에 앞 단어의 끝 글자로 시작해야 하고, 다음 사람이 이어갈 수 있도록 끝 글자까지 고려하는 경우입니다.

  • 시작 글자만 지정 — 내가 낼 수 있는 단어 전체 목록
  • 끝 글자만 지정 — 상대가 이어가기 좋은 단어 찾기(방어 단어)
  • 둘 다 지정 — 길이와 관계없이 조건에 맞는 단어만

2. 포함 글자와 자모 검색

기억나는 글자가 중간에 있을 때는 포함 글자를 씁니다. 정확한 글자가 기억나지 않으면 자모(초성·모음) 조건을 쓰면 됩니다. 예를 들어 첫소리만 기억나는 단어는 초성으로 좁히는 편이 빠릅니다.

3. 길이 제한

게임 규칙에 최소·최대 글자수가 있으면 두 값을 같이 넣습니다. 길이 조건만 단독으로 쓰면 결과가 매우 많아지므로, 시작 글자와 함께 쓰는 것이 실용적입니다.

4. 미션과 주제

미션(예: 특정 글자로 시작·끝나기)과 주제(인물, 지명, 동물 등) 조건은 함께 걸 수 있습니다. 주제는 사전에 등록된 분류를 따르며, 주제를 먼저 고르고 시작 글자를 좁히는 순서가 결과를 빨리 줄입니다.

주제별로 단어를 훑고 싶으면 주제를 하나 고른 뒤 길이 조건만 추가해 보세요. 처음 보는 단어를 익히는 용도로도 쓸만합니다.

5. 두음법칙과 표시 옵션

  • 두음법칙 — 적용 여부에 따라 "려"·"여" 같은 표기가 달라집니다. 게임 규칙과 사전 설정이 다르면 결과가 어긋나므로 확인하고 쓰세요.
  • 글자 정보 표시 — 뜻·품사 같은 부가 정보를 함께 보여줍니다. 단어를 외우는 목적이면 켜두는 편이 낫습니다.

6. 자주 막히는 지점

  1. 결과가 0건 — 조건이 너무 좁습니다. 끝 글자나 길이 조건부터 하나씩 빼 보세요.
  2. 같은 단어가 계속 보임 — 시작 글자 조건이 넓으면 흔한 단어가 상위에 반복됩니다. 길이 하한을 올리면 줄어듭니다.
  3. 상대가 이어가지 못하게 하려면 — 끝 글자가 희귀한 단어를 고르는 게 핵심입니다. 단어를 고른 뒤 그 끝 글자로 시작하는 단어 수를 확인하면 판단이 쉽습니다.
